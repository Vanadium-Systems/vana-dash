# Security

VanaDash runs in production, so please report vulnerabilities privately.

**Do not open a public issue.** Use GitHub's "Report a vulnerability" button on the Security tab
of this repository, or write to <contact@vanadium.systems> with "security" in the subject.

Include what you found, how to reproduce it and what an attacker could do with it. You will get
an answer within five working days. Once a fix is deployed you are free to publish your findings,
and you will be credited in the changelog unless you prefer otherwise.

Please do not test against `dash.vanadium.systems` or any other live deployment. Run the app
locally (see the README) and test there.

Only the latest commit on `main` is supported.
