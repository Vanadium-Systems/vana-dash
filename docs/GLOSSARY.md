# Glossary

The interface exists in Romanian and English. This is the list of terms the two share, so the
same thing has the same name on every screen. Check it before adding a string; add the term
here if it is new.

Formatting in English uses `en-GB` (day/month/year, 24-hour clock) with American spelling in
the text. Dates are always shown in the `Europe/Bucharest` time zone.
